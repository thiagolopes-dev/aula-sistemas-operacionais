aluno@linux:~$ nome_da_funcao() { }

Funções

#!/bin/bash # definindo saudacao() { echo "Olá, $1! Hoje é $(date '+%d/%m')." } # chamando — como se fosse um comando saudacao "Thiago" saudacao "Maria"

Argumentos

Dentro da função, $1, $2, $# se referem aos argumentos dela, não aos do script.

Ordem importa

A função precisa ser definida antes de ser chamada. Por isso elas ficam no topo do arquivo.

aluno@linux:~$ local variavel="valor"

A palavra local

# SEM local — a variável vaza para fora nome="Thiago" trocar() { nome="Outro" } trocar echo $nome Outro ← a função sobrescreveu sua variável # COM local — fica contida nome="Thiago" trocar() { local nome="Outro" } trocar echo $nome Thiago ← intacta

Em shell, toda variável é global por padrão — o contrário da maioria das linguagens. Sem local, uma função pode destruir dados de outra parte do script sem avisar. Use sempre.

aluno@linux:~$ return 0 / echo resultado

Devolvendo valores

# return devolve CÓDIGO DE SAÍDA, não valor arquivo_existe() { if [ -f "$1" ]; then return 0 # sucesso else return 1 # falha fi } if arquivo_existe "dados.txt"; then echo "Encontrado" fi # para devolver um VALOR, use echo e capture com $( ) soma() { echo $(( $1 + $2 )) } resultado=$(soma 10 5) echo "Total: $resultado" Total: 15

Diferença que confunde quem vem de outras linguagens: return em shell só aceita 0 a 255 e serve para dizer "deu certo ou não". Valor de verdade sai pelo echo.

aluno@linux:~$ mundo[0]="Shell Script"

Arrays

# declaração por índice mundo[0]="Shell Script" mundo[1]="Bash" mundo[2]="GNU" mundo[3]="Linux" mundo[4]="Debian" # forma compacta frutas=("maçã" "banana" "uva") # acesso echo ${mundo[3]} # Linux echo ${mundo[@]} # todos os elementos echo ${#mundo[@]} # quantos são: 5 echo ${!mundo[@]} # os índices: 0 1 2 3 4 # adicionando ao final mundo+=("Ubuntu")

Índices começam em zero, como na maioria das linguagens. E as chaves ${ } são obrigatórias — $mundo[3] sem elas não funciona.

aluno@linux:~$ for x in "${lista[@]}"

Percorrendo arrays

servicos=("nginx" "mysql" "node") # pelos valores for s in "${servicos[@]}"; do echo "Verificando $s..." done # pelos índices, quando a posição importa for i in "${!servicos[@]}"; do echo "$i: ${servicos[$i]}" done # montando o array a partir de um comando arquivos=( $(ls *.sh) ) echo "Há ${#arquivos[@]} scripts aqui"
As aspas em "${lista[@]}"

Sem elas, um item com espaço no nome vira dois itens. "Nota Fiscal.pdf" vira Nota e Fiscal.pdf — e o script processa arquivos que não existem.

aluno@linux:~$ cat menu.sh

Juntando tudo · um menu

#!/bin/bash log() { echo "[$(date '+%H:%M:%S')] $1"; } listar() { local total=$(ls -1 | wc -l) log "Há $total itens em $(pwd)" ls -lh } espaco() { log "Uso de disco:" df -h / | tail -1 } while true; do echo "" echo "1) Listar arquivos 2) Espaço em disco 3) Sair" read -p "Opção: " op case "$op" in 1) listar ;; 2) espaco ;; 3) log "Saindo."; exit 0 ;; *) echo "Opção inválida" ;; esac done

Funções, case, while, local, read — cinco aulas em vinte linhas.
