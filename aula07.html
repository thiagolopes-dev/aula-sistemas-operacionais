O laço for

#!/bin/bash echo "Testando o comando seq" for i in $(seq 1 5 100); do echo "$i" done
1 6 11 16 ... até 96

seq inicio passo fim. Aqui: começa em 1, pula de 5 em 5, para antes de passar de 100. Três números controlam o laço inteiro.

aluno@linux:~$ for --formas

As quatro formas de for

# 1. sobre uma lista escrita à mão for cor in vermelho verde azul; do echo "Cor: $cor" done # 2. sobre os arquivos do diretório for arquivo in *.sh; do echo "Encontrei: $arquivo" done # 3. faixa numérica direta for i in {1..10}; do echo "Número $i" done # 4. estilo C, quando precisa de controle fino for (( i=0; i<5; i++ )); do echo "Índice $i" done

A segunda é a mais usada no dia a dia: processar todos os arquivos de uma pasta é metade do trabalho de administração de sistema.

aluno@linux:~$ bash sequencia2.sh | wc -l

Quando o laço fica grande

#!/bin/bash # sequencia2.sh echo "Testando o comando seq" for i in $(seq 1 10 10000000); do echo "$i" done
# um milhão de linhas. Não jogue na tela — meça e conte. $ time bash sequencia2.sh > /dev/null $ bash sequencia2.sh | wc -l 1000000 # jogando na tela: interrompa com Ctrl+C $ bash sequencia2.sh ^C

Repare no > /dev/null: descarta a saída para medir só o processamento. E no | wc -l: conta em vez de mostrar. Redirecionamento e pipe transformam o laço em ferramenta.

aluno@linux:~$ x=1; for i in *; do mv $i $x; x=$((x+1)); done

Dissecando um one-liner

Renomeia todos os arquivos do diretório para números sequenciais. Cinco instruções em uma linha:

  • 01x=1 — inicializa o contador. O ; separa as instruções.
  • 02for i in * — i recebe cada nome; * pega todos os arquivos.
  • 03mv $i $x — renomeia do nome atual para o número.
  • 04x=$((x+1)) — incrementa para o próximo.
  • 05done — fecha o laço.
Regra de ouro: ensaie antes

Troque mv por echo mv e rode primeiro. Você vê exatamente o que aconteceria, sem que aconteça.

Faça isso sempre que o laço apagar ou renomear coisas. E sempre em pasta de teste — nunca no seu home.

aluno@linux:~$ while [ condicao ]; do

while e until

# while: repete ENQUANTO for verdadeiro contador=1 while [ $contador -le 5 ]; do echo "Volta $contador" contador=$(( contador + 1 )) done # lendo um arquivo linha a linha — muito usado while read -r linha; do echo "Li: $linha" done < lista.txt # until: repete ATÉ se tornar verdadeiro until ping -c1 8.8.8.8 > /dev/null 2>&1; do echo "Aguardando a rede..." sleep 3 done echo "Conectado!"

O while com read é o padrão para processar arquivos de texto: uma linha por vez, sem carregar tudo na memória.

aluno@linux:~$ break / continue

Controlando o laço por dentro

# break: sai do laço imediatamente for arquivo in *.log; do if [ ! -r "$arquivo" ]; then echo "Sem permissão em $arquivo. Parando." break fi echo "Processando $arquivo" done # continue: pula para a próxima volta for arquivo in *; do if [ -d "$arquivo" ]; then continue # ignora diretórios fi echo "Arquivo: $arquivo" done
O laço que nunca termina

while true; do :; done roda para sempre e consome 100% de um núcleo. Se acontecer sem querer: Ctrl+C. Se estiver em segundo plano: ps para achar o PID e kill PID para encerrar.

aluno@linux:~$ ./organiza.sh

Laço fazendo trabalho de verdade

#!/bin/bash # organiza.sh — separa arquivos por extensão for arquivo in *; do [ -d "$arquivo" ] && continue # pula pastas extensao="${arquivo##*.}" # o que vem depois do ponto if [ "$extensao" = "$arquivo" ]; then extensao="sem_extensao" fi mkdir -p "$extensao" mv "$arquivo" "$extensao/" echo "$arquivo → $extensao/" done

Trinta segundos de script substituem meia hora de arrastar arquivo. É esse o retorno de aprender laço.

Teste numa pasta com cópias antes de usar de verdade — e coloque echo antes do mv no primeiro ensaio.
